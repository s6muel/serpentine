# Phase 1 - Cutover: Benchmark Data

This directory contains benchmark data collected during the OPNsense 
cutover project.

## Datasets

### pre-cutover

Baseline measurements prior to cutover in controlled conditions.

### post-cutover

Measurements collected after cutover in controlled conditions.

### post-cutover-contaminated

Measurements collected after cutover with normal user activity present 
on the network. Was not included in the final analysis.
